Toast Credit Card Deposit Discrepancies — Update

Toast has fixed the dollar-level variance issue; the cent-level rounding issue is still on track for an end-of-August fix

Following up on our previous announcement about Credit Card Deposit discrepancies, Toast has shared an update covering two separate issues.

Dollar-Level Variances — Fixed
Toast identified a separate bug — unrelated to the rounding issue reported previously — that caused the dollar variances some merchants saw between the Toast Orders API and the Toast Payout report. The issue was in how the Orders API displayed data; the actual payout amounts were accurate throughout. Toast fixed this in early August 2026, so you should no longer see these dollar-level variances going forward.

Cent-Level Rounding — Still In Progress
The smaller, cent-level rounding discrepancies described in our previous announcement are a separate, known issue. Toast is still targeting an official fix by the end of August 2026 and will confirm exact timing once available.

If you notice any new dollar-level variances after early August 2026, please let us know so we can report it back to Toast.

Thank you for your patience. We'll share another update once Toast confirms the rounding fix timeline.
